# 意見プロファイル指標一覧

## 1. 文章量・構成に関する指標

| 指標名 | 定義・判定方法 |
|--------|----------------|
| **大問の問題文文字数** | 問題番号を除き、最初の小問（(1)など）が始まるまでの設問文の総文字数。 |
| **小問の総文字数** | (1), (2), (3)①... といった、各小問の問いの文章の合計文字数。 |
| **与えられる数値の個数** | 大問の問題文や図で明示的に指定されている長さや値の数。 |
| **小問の数（解答要求数）** | 解答が要求される問いの総数（例：(3)① と (3)② は別々にカウント）。 |
| **小問ごとの要求種別** | 各小問が何を求めているかを直接分類します。<br>□ 長さを求める<br>□ 面積を求める<br>□ 体積を求める<br>□ 最短距離を求める<br>□ 角度を求める<br>□ 比を求める |
| **立体の構成** | 問題の立体が単一か、組み合わせかを判定します。<br>□ 単一の立体（直方体のみ、三角すいのみ等）<br>□ 複数の立体の組み合わせ |

## 2. 解答形式に関する指標

| 指標名 | 選択肢（分類リスト） |
|--------|----------------------|
| **解答の形式（小問ごと）** | □ 整数<br>□ 既約分数<br>□ 無理数($\sqrt{}$) |
| **小問ごとの要求単位** | 各小問で求められる解答の単位。<br>□ cm（長さ）<br>□ $cm^2$（面積）<br>□ $cm^3$（体積）<br>□ 度（角度）<br>□ 単位なし（比など） |
| **正答例での補助点の使用** | 正答例（新潟県2022-A.pdfなど）の中で、問題文にない新しい点（M, N, Rなど）を定義しているか。<br>**(Yes/No)** |

## 3. 使用単元に関する指標

| 指標名 | 選択肢 |
|--------|--------|
| **単元（設定）**<br>（問題文や図の構成要素） | **【2D図形】**<br>□ 正方形<br>□ 長方形<br>□ 正三角形<br>□ 二等辺三角形<br>□ 直角三角形<br>□ 台形<br>□ 円<br><br>**【3D図形】**<br>□ 直方体<br>□ 立方体<br>□ 正四角すい<br>□ 三角すい<br>□ 円すい<br>□ 三角柱<br>□ 円柱<br><br>**【条件・概念】**<br>□ 平行<br>□ 垂直・垂線<br>□ 中点<br>□ 交点<br>□ 平面 |
| **単元（解法）**<br>（正答例で使用される定理・手法） | **【定理】**<br>□ 三平方の定理<br>□ 相似（図形の相似）<br>□ 中点連結定理<br>□ 円周角の定理<br><br>**【公式】**<br>□ 面積の公式（三角形、四角形など）<br>□ 体積の公式（すい体、柱体など）<br><br>**【概念・性質】**<br>□ 平行と比<br>□ 相似比<br>□ 面積比<br>□ 体積比<br>□ 二等辺三角形の性質<br>□ 正三角形の性質<br><br>**【手法】**<br>□ 展開図（最短距離など）<br>□ 補助線（交点の追加など） |

## 4. 図形に関する指標

| 指標名 | 定義・判定方法 |
|--------|----------------|
| **総頂点・点の数** | 問題文および図でアルファベット（A, B, C... P, Q...）が振られている点の総数。 |
| **動点の有無** | 「辺XX上を...移動する点P」のように、移動が定義されている点が存在するかどうか。<br>**(Yes/No)** |
| **図中に明記された数値の個数** | 図形のイラスト内に直接「3 cm」や「4 cm」のように書き込まれている数値の総数。 |

## 5. 解法プロセスと認知負荷に関する指標

| 指標名 | 定義・判定方法 |
|--------|----------------|
| **解法のステップ数** | 正答例の中で、論理的に区切りがつく計算や推論の単位の総数。<br><br>例えば、「①三平方の定理で辺ABの長さを求める」「②△ABCと△ADEの相似を証明する」「③相似比を使って辺DEの長さを求める」という解答は3ステップとカウントします。 |
| **論理的分岐の有無** | 解法プロセスにおいて、場合分け（例：「$x > 0$ のとき」「$x \le 0$ のとき」）が必要となるか。<br>**(Yes/No)**<br><br>これは解法のアルゴリズム的な複雑さを示します。 |
| **使用定理・公式の数** | 正答例の中で、名前のついた定理（三平方の定理、中点連結定理など）や公式（面積、体積の公式など）が、ユニークな種類でいくつ使われているかの総数。 |
| **複数単元の知識統合の要否** | 解答にたどり着くために、異なる単元（例：「図形の相似」と「二次方程式」）の知識を組み合わせて利用する必要があるか。<br>**(Yes/No)** |
| **無関係な情報の有無**<br>（外発的認知負荷） | 問題文や図に、正答例の導出プロセスで一切使用されない数値や条件が含まれているか。<br>**(Yes/No)**<br><br>これは、解答者が解法に関係のない情報を意図的に無視する必要があるかを示します。 |
